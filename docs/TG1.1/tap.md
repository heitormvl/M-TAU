# TAP - Termo de Abertura do Projeto: M-TAU

* **Nome do Projeto:** M-TAU (Marketplace de Tecnologias Assistivas Usadas).
* **Gerente de Projeto:** Heitor Maciel de Vasconcellos Leite.
* **Disciplina:** Laboratório de Engenharia de Software - 2026.1.
* **Instituição:** Universidade Presbiteriana Mackenzie.

## 2. Justificativa e Objetivos

* **Tema:** Acessibilidade e inclusão.
* **Problema Real:** Centralizar e democratizar o acesso a tecnologias assistivas, que costumam ter alto custo e oferta dispersa.
### **Objetivo Geral:**
* Desenvolver um software completo (MVP) que funcione como um marketplace para tecnologias assistivas.
### **Objetivos Específicos:**
* Permitir o anúncio de produtos por parte dos vendedores.
* Prover pesquisa detalhada com filtros técnicos adequados às necessidades de acessibilidade.
* Intermediar a negociação entre as partes e o processamento de pagamentos.

## 3. Escopo do MVP

### Funcionalidades (Inclusas)
* **Cadastro de Usuários e Produtos:** Gestão de perfil e inventário de tecnologias assistivas.
* **Busca Especializada:** Filtros baseados em categorias de deficiência e especificações técnicas.
* **Chat Interno:** Canal de comunicação direto entre comprador e vendedor.
* **Gateway de Pagamento:** Integração com API externa para transações financeiras.
* **Sistema de Avaliação:** Feedback qualitativo para vendedores e compradores.

### Limites do Projeto (Não Inclusos)

* Logística e transporte (frete por conta dos usuários).
* Gestão de reclamações, devoluções ou suporte jurídico.
* Verificação de identidade via documentos oficiais.
* Carteira digital (E-wallet) proprietária no app.
